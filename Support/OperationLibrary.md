# 操作库与菜单编排

设置分为操作库、菜单编排、通用设置。操作库保存执行参数；菜单节点保存操作 ID 引用、名称覆盖、显示状态及可选的内置图标 ID。操作支持多处引用，自定义操作复制时生成独立 ID，不复制菜单引用。新增操作不会改变菜单。内置操作不提供编辑、复制、启停或删除入口，批量删除也保留内置实例及其引用。

操作类型统一为工具操作、文件模板、传送目录、快捷目录、应用入口、自定义图标、自定义脚本。类型筛选、新增菜单、操作库卡片、菜单编排状态、操作选择器和详情类型均使用操作注册表的同一份名称；内置／自定义来源标记独立展示。菜单分组名称属于用户编排，不随类型文案修改而覆盖。

操作卡片默认高 56 点，卡片间距 6 点。第一行左侧为名称、最右侧为状态，第二行为类型和操作说明；长名称、状态及路径截断显示并保留完整 tooltip。日常模式不显示启用控件或操作下拉框，自定义操作双击编辑、右键菜单管理；批量模式仅自定义操作在左侧显示选择控件，内置操作不参与批量选择，状态位置不变。新增下拉菜单直接打开对应文件、目录、应用或脚本选择器；导入在后台准备，全部成功后一次提交，失败清理本次创建的资产副本。

操作库顶部使用紧凑工具栏：搜索、类型和状态筛选靠左，批量删除与新增靠右，两组之间留白，按原生控件的对齐区域垂直居中。搜索框宽度最多 180 点，不拉伸填满剩余空间；使用随窗口主题变化的轻透渐变背景，文字、搜索图标和编辑区域保留原生布局，焦点轮廓匹配圆角背景。“批量删除”为普通按钮，点击后进入勾选模式，显示“取消”和“删除”；未选自定义操作时禁用删除，取消退出模式并清除选择。删除按钮直接确认所选自定义操作及其引用，取消确认保留选择，确认后一次提交并留在勾选模式。不提供批量加入菜单，单项右键的加入菜单及菜单编排选择器保留。工具栏按当前筛选文案及按钮测量宽度，空间不足时将右侧操作整体换行。

进入操作库或重新打开设置窗口时，搜索框不自动进入编辑；可点击搜索框或通过 Tab 进入搜索。搜索编辑期间，在设置窗口内点击框外会结束编辑并保留查询内容，原点击继续交给对应控件；菜单名称编辑与所属弹窗按各自的焦点流程处理。

内置操作详情使用图标、标题及来源／类型展示，参数以可选择复制的静态信息行呈现，不使用禁用的下拉框和复选框。首次及再次打开不自动选中名称；窗口高度随内容收紧，仅提供关闭，自定义操作的编辑表单保持可编辑。

操作库中的应用入口和自定义图标只展示图标，不提供图标修改入口；其余可编辑操作的图标选择器提供内置图标及“不显示图标”，不提供“使用默认图标”。图标修改随草稿保存，取消不写配置。

自定义脚本的默认图标（`iconID` 为 nil 或 `category.scripts`）自动识别 Shell、Python、JavaScript、TypeScript、Ruby、Perl、PHP、Lua、Swift、AppleScript，使用项目自绘矢量标识，无法识别时保留通用终端图标。彩色风格使用对应标识及配色，纯色风格使用同一轮廓；手选其他图标及“不显示图标”仍优先。识别以首行 shebang 为准，无 shebang 才按后缀识别；未知或无效的 shebang 不根据后缀猜测。识别不要求安装解释器，不改变脚本执行支持范围。

## 配置与通信

`AppConfiguration` 的格式版本为 1。主应用使用 `operations-v1.json`，Finder 扩展使用独立的 `finder-operations-v1.json` 广播缓存。旧 `configuration.json` 不读取、不迁移、不覆盖。

`ConfigurationStore.update` 在一次提交中校验、原子保存、发布通知。结构校验拒绝重复 ID、嵌套分组和三级菜单；缺失引用保留供编辑器诊断。无法读取的新格式文件不会被默认配置覆盖。未知类型的参数作为 JSON 值保留，不执行，也不自动清理。

配置通知与请求分别使用 `dev.crab.operations.v1.configurationChanged`、`dev.crab.operations.v1.configurationRequest`。主应用持久化数据不含预览，广播副本包含可重建的预览和可用状态。文件检查在后台执行，AppKit 图像绘制分批回到主线程；自定义图片先通过 ImageIO 生成有界缩略图。

脚本语言预览在后台只读取普通文件的前 4096 字节，语言 ID 保存在 `OperationPreview.scriptLanguageID` 并随预览广播，不写入主配置。Finder 和菜单编排通过语言 ID 重绘内置标识，不读取脚本；旧预览缺少语言 ID 时使用通用终端图标。菜单引用的默认图标继续继承操作库，单独设置的引用图标保持独立。

## 新增操作类型

1. 在共享层定义类型专属参数及其 Codable 分支，并向 `OperationRegistry` 注册 `OperationDefinition`：类型标识、名称、图标类别、参数校验及上下文适用条件。
2. 在主应用的 `OperationUIRegistry` 注册编辑字段、草稿创建和卡片摘要；需要时提供卡片局部内容及高度。外框、批量选择、右键菜单和状态仍由通用卡片管理。编辑器先修改本地草稿，保存时一次提交，取消不写配置。
3. 向 `ActionRouter` 注册该类型的执行适配器，复用现有文件、图片、应用、归档和脚本服务，并按请求传递参数。

菜单编辑器、`MenuPlanner` 和 Finder 动作桥接按类型注册表工作，不需要新增类型分支。新增类型仍须补充对应参数解码、校验、编辑与执行测试。

## 菜单与执行

菜单根节点允许操作引用或分组，分组内只允许操作引用。编辑器左侧展示一级菜单，右侧跟随左侧分组选择展示二级操作。新建分组直接插入列表、选中并进入名称编辑，不弹出名称对话框。两侧支持拖拽排序，操作可在组内、跨组或一级／二级之间移动；双击只修改当前菜单引用的名称。

首次配置按顺序提供新建文件、文件（夹）操作、由 APP 打开、发送到…、收藏目录、自定义图标、图片转换、压缩与解压八个分组，现有内置操作各引用一次。发送快捷方式到桌面、隔空投送及复制／移动操作归入发送到；添加到常用目录归入收藏目录。默认分组用 `defaultNameKey` 保存固定文案键，随语言切换；用户改名保存在 `name`，保留原文。分组图标使用已有分类图标。

已保存的编排按原样加载，包括空菜单。一级工具栏从左到右为新建分组图标、＋添加操作、－移除选中项，右侧为重置全部菜单图标；二级工具栏提供＋、－和重置当前分组图标。图标按钮带本地化悬停提示与无障碍名称，未选择适用目标时禁用对应按钮。

“重置全部菜单”按当前操作库中仍存在的内置操作恢复默认八组及其引用，不修改操作库、操作参数或通用设置；非空菜单先确认，空菜单直接恢复。“重置当前分组”只对默认分组启用，确认后仅恢复该组下的默认操作与引用显示设置，保留组名称、图标、显示状态和其他分组。默认分组通过稳定 ID 识别，改名不影响重置；自定义分组不处理。原默认引用已被移往其他分组时保留原位置，为本组恢复的引用分配独立 ID。每次重置只提交一次配置，取消不写入。清空菜单、重启或新增操作均不会触发自动回填。

“添加操作…”使用附属于当前窗口的卡片选择 Sheet，支持搜索和类型筛选。点击卡片多选，选中项显示角标，切换筛选保留已选 ID；确认后按操作库顺序一次添加到当前一级菜单或分组。该弹窗不提供操作新增、编辑、复制和删除，取消不修改配置；提交前重新检查操作及目标分组是否仍存在。

选择 Sheet 打开时不自动进入搜索输入，可点击搜索框或通过 Tab 开始输入。搜索期间点击标题、卡片、筛选器或空白区域会结束搜索编辑，保留查询文字及已选操作，并继续处理该次点击；搜索框内部点击和列表异步刷新不会中断输入。该行为与操作库主窗口复用同一焦点处理。

操作库、菜单两栏、通用设置及操作／图标选择弹窗使用原生小尺寸浮动滚动条。内容无需滚动时隐藏，滚动时由 AppKit 显示并管理闲置淡出，避免常驻的粗轨道；保持原有内容尺寸和滚动操作。

行首图标单击只选中行，自定义图标操作不允许更换菜单图标，应用入口及其他操作、分组可双击打开内置图标选择器，来源为现有分类图标、Crab 自有矢量符号及系统图标目录，不上传图片。分类图标以 `category.<rawValue>` 保存，彩色时保留各分类配色，纯色时使用同一轮廓的模板图形。`MenuNode.iconID` 为 nil 时跟随操作库中对应操作的图标配置（包括自定义脚本），“使用默认图标”清除当前引用的图标覆盖；分组保持自身默认图标。`none` 为不显示，其余为内置目录 ID。未知图标 ID 保留并回退到默认图标；图标设置跟随节点移动，互不影响其他引用。通用设置不再保存按类型的图标开关。彩色／纯色风格继续全局统一，原生系统图标保留原色。

应用入口未检测到可用安装且没有原生 Logo 时，操作库、菜单编排、选择器和详情统一显示“应用窗口＋圆形减号”占位图标；彩色使用应用分类配色，纯色使用模板轮廓。占位不写入操作或菜单图标设置，不充当原生图标广播预览，也不改变应用可用状态；Finder 仍隐藏不可用应用。显式设置的图标及不显示图标优先。

两栏的按钮及列表放在使用相同语义实色的独立背景卡片内，底色不受窗口背后内容影响。列表显式允许名称和按钮成为第一响应者。名称字段直接接收双击并进入原生字段编辑器，显示与实际编辑文字使用同一垂直居中文字区域，编辑器保持透明背景；未改名时不提交配置。显示勾选按稳定节点 ID 保存按钮状态，未勾选的节点不进入菜单，隐藏分组不改变子项各自的勾选状态。配置通知在名称编辑及按钮鼠标跟踪期间延后重建，结束后合并刷新并保留滚动位置。

运行时隐藏不可用、禁用、不适用、缺失或手动隐藏的引用，并隐藏最终为空的分组。二级菜单不加入分隔项。Finder 与备用菜单复用 `ContextMenuBuilder`。

`ActionRequest` 协议版本为 2，仅携带操作 ID、选中路径和当前目录，不携带执行参数。主应用根据当前配置重新查找并校验后执行，删除、禁用或已不适用的操作停止派发。Finder 主对象保留 selector 和 tag 到请求快照的映射，不依赖跨桥接的 `representedObject`。后台启动、剪切恢复和原有文件安全规则由现有服务继续执行。

删除引用或分组不删除操作。删除操作在同一次配置提交中清理其全部引用，不删除原始模板、图片、脚本、目录或应用。
